## 시작하기

1. ZIP을 내려받아 압축을 모두 풉니다.
2. `blogon` 폴더의 `start.cmd`를 실행하고 실행 창을 켜둡니다.
3. `블로그온-열기.url`을 열어 대시보드에 접속합니다.
4. 동봉된 `사용안내.md`에 따라 본인의 Gemini 키, 네이버 계정, Chrome 확장을 설정합니다.

Windows용 Node 실행기가 포함되어 있습니다. 개인 계정·API 키·원고는 포함하지 않습니다.
